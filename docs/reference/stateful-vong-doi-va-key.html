Stateful, vòng đời & Key

Tra nhanh. Giải thích đầy đủ ở bài 0005 và bài 0006.

Vòng đời — chạy khi nào, đặt gì vào

HàmChạy khi nàoĐặt gì
createState()Một lần, trước tất cảKhông gì cả — chỉ => _State()
initState()Đúng một lầnTạo controller, mở subscription, gọi API lần đầu
didChangeDependencies()Sau initState + mỗi khi thứ đọc qua context đổiViệc phụ thuộc Theme, MediaQuery
build()Rất nhiều lầnChỉ dựng widget. Không mạng, không file, không parse
didUpdateWidget()Mỗi lần cha dựng lại — kể cả khi không gì đổiSo oldWidget trước, rồi mới phản ứng
dispose()Một lần, khi bị gỡ hẳnTrả lại mọi thứ mượn ở initState

didUpdateWidget không so giá trị giùm bạn. Không có if (oldWidget.x != widget.x) bên trong là bug đang chờ — xem record 0002.

setState làm ba việc

setState(() => _counter++);
// 1. chạy hàm bạn đưa vào — giá trị đổi NGAY, đồng bộ
// 2. đánh dấu State này "bẩn"
// 3. xin Flutter xếp lịch gọi build() ở khung hình SAU
Tình huốngKết quả
Sửa biến ngoài setStateGiá trị đổi thật, màn hình đứng im
setState mà không đổi gìVẫn tốn một lần build
setState sau khi disposeNém lỗi — chắn bằng if (mounted)

Quên dispose thì sao

ThứHậu quả
Timer / Timer.periodicVẫn nổ đều sau khi màn đã đóng
StreamSubscriptionVẫn nhận dữ liệu, gọi setState trên State đã chết
TextEditingControllerGiữ listener, rò rỉ bộ nhớ
AnimationControllerGiữ ticker, đốt CPU mãi mãi
FocusNode, ScrollControllerRò rỉ tương tự

Mượn ở initState thì trả ở dispose. Viết cặp với nhau, đừng để lát nữa.

Chọn loại Key

LoạiGhép theoDùng khi
ValueKeyMột giá trị — id, emailMặc định, 90% trường hợp
ObjectKeyDanh tính của objectKhông có id nhưng object thì duy nhất
UniqueKeyKhông gì — luôn khác chính nóMuốn ép vứt State cũ, reset sạch
GlobalKeyToàn appChạm State từ ngoài, hoặc giữ State khi đổi chỗ trong cây. Đắt

Chỉ cần Key khi cả ba điều cùng đúng:

1Có danh sách widget anh em cùng kiểu
2Danh sách bị xoá / thêm / đảo thứ tự
3Các widget đó có State để mà mất

Key phải nằm trên chính widget bị xê dịch, cùng tầng với anh em của nó. Dán vào widget con bên trong là vô tác dụng.
